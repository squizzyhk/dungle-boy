# Project instructions

## Release notes

For every release in this project, match the owner's Squarepad release-note voice, without cursing. Use `docs/releases/v0.2.0.md` as the local reference.

- Title: `dungle boy <version>: <short lowercase headline>`.
- Open with a casual greeting appropriate to the update, followed by a bold headline.
- Add one short paragraph explaining what players get in plain language.
- Follow with `the big stuff:` and bullets led by bold phrases. Use conversational, mostly lowercase prose.
- Include an honest `FYI` paragraph for limitations, pending work, or assets that are not yet playable features.
- Close with a link to `CHANGELOG.md`, then `bless up`, then the exact signoff `squiz + caspa + the machines`, separated by blank lines.
- No cursing, emoji, em dashes, invented claims, or test counts in the release body. Keep verification details in the documentary changelog.
- Save release bodies under `docs/releases/`, update `CHANGELOG.md`, and keep package and lockfile versions aligned with the release tag.
