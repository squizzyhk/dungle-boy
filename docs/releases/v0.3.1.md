hey friends. **dungle boy is online.**

the little dude has a proper home on doblins.xyz now, so you can open the game in a browser and share the same link with friends.

- **one easy link.** dungle boy now loads from `doblins.xyz/dungleboy/`
- **all the art comes along.** courses, character animation, obstacles and pickups load from the new home
- **sound made the trip.** the menu theme and gameplay sound effects use the same shared web address
- **doblins stays put.** the main doblins game keeps its own homepage and routes

FYI this is still the same v0.3 game underneath. the hosting update gives it a public home but doesn't add new courses or gameplay. browsers may still need a click or tap before music starts.
